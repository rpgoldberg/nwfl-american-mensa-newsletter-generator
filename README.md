# nwfl-american-mensa-newsletter-generator
Data-driven generator to produce the NW Florida American Mensa Newsletter in PDF format

Initial version is designed to generate the previously MS Publisher formatted newsletter exported in PDF format directly from the data in a format very closely resembling the original layout in MS Publisher. Some of the logic is still too specific to adapt to new monthly text and will be the focus area for additional refinements in subsequent versions. Since some content is not for public visibility, only an empty json data stub is provided for consumption.
